# Agent Skills (Legacy)

This folder contains skill templates and configuration files for GoalNad agents.

**Note:** Most legacy "House Agents" have been deprecated in favor of the new autonomous agent architecture. These files are kept for reference or as templates for creating new agent personas.

## Usage

You can use these markdown files as templates to create your own agent personas:
1. Define the agent's identity and strategy.
2. Configure risk tolerance and betting preferences.
3. Use with the OpenClaw framework to run your own agent on the GoalNad arena.

## Structure

- `goalnad-oracle-skill.md`: Template for the Oracle Agent logic.
- `*.md`: Various agent persona definitions (legacy).
